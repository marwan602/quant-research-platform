Note on Rank ICIR

Rank ICIR is calculated as the mean daily cross-sectional Spearman rank correlation divided by its standard deviation over the out-of-sample evaluation period. The Temporal Attention Transformer achieved a Rank ICIR of 2.058 (vs 1.265 for Attentive LSTM and 1.161 for LightGBM), reflecting a higher average ranking signal relative to its day-to-day variation.

System Specification & Methodology

Technical reference specification of data pipelines, factor formulations, neural architecture, and cloud automation.

1
Point-in-Time Universe & Survivorship-Bias Mitigation

The platform reconstructs the verified historical constituent membership of the S&P 500 on every trading day from 2015 to present, reducing survivorship bias from bankruptcies, acquisitions, and delistings.

Technical Details

On each historical date, candidate equities are filtered strictly through the point-in-time constituent registry. Ticker symbol changes are tracked across corporate actions. Daily coverage checks verify that historical members have valid daily bars before feature calculation.

2
Alpha158 Factor Suite

A suite of 158 normalized quantitative technical indicators measuring price dynamics, multi-scale momentum, trailing volatility, and volume concentration across a 60-day rolling lookback window.

Technical Details

Features include normalized candle bodies (KMID, KLEN, KSFT), relative price channels, multi-scale rate of change (ROC5 through ROC60), return dispersion, moving average volume turnover, and volume-weighted average price (VWAP) relationships. Input tensors have shape [N, 60, 158].

3
Temporal Attention Transformer Architecture

A sequence-to-scalar architecture utilizing multi-head self-attention to capture direct non-linear interactions across all 60 time steps, projecting to expected 5-day return forecasts.

Technical Details

Features are projected to model dimension d_model = 64 with learned positional encodings, processed through 2 multi-head attention layers (4 heads), temporal attention pooling, LayerNorm, and a feed-forward projection head. Total parameters: 98,881 (397 KB checkpoint). CPU inference latency is approximately 10 seconds for 501 equities.

4
Friction Accounting & Rebalancing Protocol

Portfolios rebalance every 5 trading days. A transaction cost of 10 basis points (0.10%) per unit of portfolio turnover is deducted directly from gross returns.

Technical Details

Net return is computed as R_net(t) = R_gross(t) - Turnover(t) * 0.0010. Portfolios hold 50 equal-weighted equities (2.0% target weight each). Turnover is measured as half the sum of absolute weight changes across rebalance sessions.

5
Automated Serverless Cloud Orchestration

An automated pipeline executed by GitHub Actions every weekday after market close at 22:00 UTC. Ingests raw market bars into private storage and publishes derived research forecasts to GitHub Pages.

Technical Details

The workflow uses dual-repository separation to keep raw price data confidential while publishing public forecasts. The pipeline validates that the ingested market date matches target date, checks constituent coverage (≥90%), evaluates inference coverage (≥85%), and updates the static JSON payloads feeding this site.
