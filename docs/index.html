Quantitative Methodology & Cloud Architecture

Rigorous end-to-end specification covering point-in-time universe construction, Alpha158 factor formulation, attention mechanics, transaction cost modeling, and autonomous GitHub Actions orchestration.

1. Point-in-Time Universe & Elimination of Survivorship Bias

Backtesting only against current index members introduces severe survivorship bias by retroactively including future winners while excluding historical constituents that were delisted, went bankrupt, or were acquired.

This research platform strictly enforces point-in-time universe membership using daily historical index constituents from 2015 to present. On each historical trading day, the candidate universe consists exclusively of equities that were verified S&P 500 members on that specific date.

2. Alpha158 Factor Engineering Engine

For every active stock, the feature pipeline computes 158 normalized quantitative technical indicators over a 60-day historical lookback window:

  • Normalized Bar Dynamics (KMID, KLEN, KSFT): Proportional candle bodies, shadows, and intraday range skewness normalized by opening price and daily spread.
  • Relative Price Channels: Normalized Open, High, Low, and Volume-Weighted Average Price (VWAP) relative to Close.
  • Rolling Return Momentum (ROC5, ROC10, ROC20, ROC30, ROC60): Rate-of-change indicators capturing multi-scale momentum dynamics.
  • Volatility & Dispersion (STD5, STD20, STD60, BETA): Trailing return dispersion and market covariance.
  • Volume Dynamics & Liquidity (VOLUME_RATIO, VSTD, WVMA): Moving average volume turnover and price-weighted volume concentration.
Input Tensor Dimensions: [Batch Size: N Equities, Sequence Length: 60 Trading Days, Features: 158 Normalized Factors]

3. Temporal Attention Transformer Architecture

Unlike recurrent models (LSTM / GRU) which compress sequential states into a single hidden vector and struggle with long-range factor interactions, the Temporal Attention Transformer computes direct non-linear interactions across all 60 time steps:

Each stock's temporal representation is passed through multi-head self-attention:

Attention(Q, K, V) = softmax((Q * K^T) / sqrt(d_k)) * V

The attention outputs are passed through LayerNorm, dropout regularization, and a residual feed-forward network to project directly to the 5-day expected return target:

y_hat = W_out * ReLU(W_fc * ContextVector + b_fc) + b_out

4. Evaluation Protocol & Transaction Cost Accounting

Out-of-sample evaluation strictly avoids lookahead bias:

  • Training Split: 2015-01-01 to 2021-12-31 (In-Sample Calibration).
  • Validation Split: 2022-01-01 to 2023-12-31 (Hyperparameter Optimization & Early Stopping).
  • Test Split: 2024-01-01 to 2026-08-20 (Strict Out-of-Sample Holdout).
  • Rebalance Horizon: 5 trading days non-overlapping portfolio rebalancing.
  • Friction Accounting: 10 bps (0.10%) per unit of portfolio turnover deducted directly from gross returns:
R_net(t) = R_gross(t) - Turnover(t) * CostRate
